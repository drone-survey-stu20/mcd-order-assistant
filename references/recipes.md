# 场景化搭配方案

用户按需求而非按菜名点餐时，直接查此表给出方案。所有卖点仍须引自 `mcd_products.json` 的官网原文，不得改写。

## 早餐 / 早八通勤

麦当劳早餐品类有限，且**商品库未收录早餐 SKU**。以下是用非早餐商品拼出的通勤替代方案，不是麦当劳早餐套餐：

| 想要 | 推荐 | 官网卖点方向 |
|---|---|---|
| 扎实顶饿 | 板烧鸡腿堡 + 咖啡 | 原块去骨鸡排嫩滑多汁，0 油煎制 |
| 快而不贵 | 吉士汉堡包 | 100% 纯牛肉配香软芝士 |
| 清爽开场 | 圆筒冰淇淋 + 可口可乐 | 醇香冰淇淋配香脆圆筒（注意热量） |

⚠️ 早餐具体供应时段与门店差异大。**商品库当前未收录任何早餐类商品**，用户问早餐品类时不要臆造早餐 SKU，应说明库覆盖范围并引导用户以门店实际供应为准（或通过 MCP 查询）。下表是用非早餐商品拼出的早餐替代方案，不是麦当劳早餐套餐。

## 加班 / 夜宵

| 想要 | 推荐 | 官网卖点方向 |
|---|---|---|
| 扛饿顶配 | 巨无霸 + 麦乐鸡 + 可乐 | 双层纯牛肉饼 + 锁汁嫩滑鸡肉 |
| 重口解馋 | 麦辣鸡腿汉堡 + 麦辣鸡翅 | 为"中国胃"研发，金黄脆辣 |
| 别太腻 | 双层吉士汉堡 + 无糖可口可乐 | 双层芝士，无糖解腻 |

夜宵场景优先高热量档套餐，脚本会用"扎实饱腹组合"这类命名。

## 儿童 / 小朋友

| 想要 | 推荐 | 官网卖点方向 |
|---|---|---|
| 均衡不挑食 | 苹果片 + 玉米杯 | 优选山东红富士清爽酸甜；玉米粒粒饱满多汁 |
| 蛋白质补充 | 麦香鱼 | 深海鳕鱼饼，鲜嫩多汁 |
| 儿童餐 | 开心乐园餐 | ⚠️ 商品库未收录具体 SKU，需引导至门店或 MCP 查询 |

孩子场景优先小食与低刺激口味，避开过辣（麦辣鸡腿汉堡、麦辣鸡翅）。

## 控制能量 / 健身

| 想要 | 推荐 | 能量 |
|---|---|---|
| 最低热量 | 吉士汉堡包 + 玉米杯 + 无糖可口可乐 | 约 1454千焦 |
| 补充蛋白 | 麦香鸡 + 圆筒冰淇淋 | 约 1937千焦 |
| 单餐控量 | 单点汉堡 + 无糖可乐 | 按商品库实际值 |

控能量场景优先：无糖可口可乐（0 千焦）、苹果片（133 千焦）、玉米杯（223 千焦）替代含糖饮料与高脂小食。

## 请客 / 多人分享

| 想要 | 推荐 | 说明 |
|---|---|---|
| 稳妥不出错 | 巨无霸 + 麦辣鸡腿汉堡 + 双层吉士汉堡 + 薯条(大) + 可乐 ×N | 经典款覆盖各口味偏好 |
| 想有话题 | 芝士安格斯厚牛堡 + 培根蔬萃双层牛堡 | 厚牛堡系列，分量感强 |
| 配齐甜品 | 再加奥利奥麦旋风 + 朱古力新地 | 甜品两款口味分歧小，接受度高 |

分享场景需先确认**人数**再定分量，不要按单人量推荐。

## 减脂 / 低负担

| 想要 | 推荐 |
|---|---|
| 最省 | 无糖可口可乐 + 苹果片（合计 133千焦） |
| 有饱腹感 | 吉士汉堡包（1231千焦）+ 无糖可乐 |
| 甜品替代 | 圆筒冰淇淋（391千焦）优于新地与麦旋风 |

## 场景速查一句话版

- 饿了 → 双层吉士汉堡 / 巨无霸
- 想吃辣 → 麦辣鸡腿汉堡 + 麦辣鸡翅
- 要清爽 → 无糖可乐 + 苹果片 / 玉米杯
- 给孩子 → 苹果片 + 玉米杯 + 麦香鱼
- 熬夜 → 高热量档套餐（脚本自动命名"深夜"系列）
- 请客 → 先问人数，再按汉堡 + 小食 + 甜品 + 饮品 ×N 配齐

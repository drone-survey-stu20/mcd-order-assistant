## 场景速查一句话版

- 饿了 → 双层吉士汉堡 / 巨无霸
- 想吃辣 → 麦辣鸡腿汉堡 + 麦辣鸡翅
- 要清爽 → 无糖可乐 + 苹果片 / 玉米杯
- 给孩子 → 苹果片 + 玉米杯 + 麦香鱼
- 熬夜 → 高热量档套餐（脚本自动命名"深夜"系列）
- 请客 → 先问人数，再按汉堡 + 小食 + 甜品 + 饮品 ×N 配齐

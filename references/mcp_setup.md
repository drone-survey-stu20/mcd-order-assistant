# 麦当劳官方 MCP 接入参考

## 能力概览

麦当劳中国开放平台提供的远程托管 MCP Server（**非** WorkBuddy 连接器市场里的连接器，需手工配置），覆盖三大业务场景：

| 能力 | 说明 |
|---|---|
| 智能点餐 | 集成点餐与下单能力（麦乐送外送全流程） |
| 活动日历 | 麦麦日历，提供当前进行中的促销活动信息 |
| 优惠券 | 全量优惠券查询与自动领取、积分余额查询与兑换 |

平台地址：https://open.mcd.cn/mcp
文档地址：https://open.mcd.cn/mcp/doc

## Token 申请流程

1. 打开 https://open.mcd.cn/mcp/doc
2. 点击右上角【登录】，用手机号验证登录
3. 登录后右上角变为【控制台】，点击进入
4. 点击激活按钮，申请 MCP Token
5. 同意服务协议
6. Token 申请成功，可一键复制

## 配置方式

写入 `~/.workbuddy/mcp.json`（注意不是 `.workbuddy/.mcp.json`）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

**传输协议**：Streamable HTTP
**限流**：每个 Token 每分钟最多 600 次请求，超出返回 429

## 启用步骤

写入配置后 MCP 不会自动生效。需在WorkBuddy 中：连接器管理页右上角 → 自定义连接器入口 → 对新服务器点击「信任」。

## 安全要求

- Token 属敏感凭据，只存于 `~/.workbuddy/mcp.json`，**禁止**写入技能目录、`references/`、或任何会被打包分发的位置
- 禁止在对话中完整回显 Token
- 分享技能时先确认目录内无凭据残留

## 降级策略

MCP 未配置或调用失败时，技能的核心功能仍须可用：

| 功能 | 无 MCP 时 |
|---|---|
| 商品推荐（官网数据） | ✅ 可用 |
| 随机混搭套餐 | ✅ 可用 |
| 点餐记录与统计 | ✅ 可用 |
| 优惠券领取 | ❌ 不可用，需告知用户 |
| 活动日历 | ❌ 不可用，可降级为 WebFetch 官网活动页 |
| 真实下单 | ❌ 不可用，只输出推荐方案 |

调用 MCP 工具时若报错（如 401 鉴权失败、429 限流），不要反复重试——明确告知用户原因，并继续用本地商品库完成推荐部分。

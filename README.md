# 麦门点餐助手 · mcd-order-assistant

> 不知道吃什么的时候，让 AI 帮你配一套麦当劳——不只是推荐，还会念一段顺口溜。

---

## 项目介绍

一个基于**麦当劳官方 MCP Server** 的点餐助手 Skill。它能读懂你的场景（早餐/加班/夜宵/给孩子/想控热量/请客），从**158 个餐品**里配出一套套餐，给出**官网原文卖点 + MCP 官方营养数据 + 押韵顺口溜**，并记住你每次点了什么。

商品库由两份权威数据源合并而成：**营养成分来自麦当劳 MCP `list-nutrition-foods`（160 个餐品）**，**卖点描述来自麦当劳官网产品页原文**。因此早餐、儿童餐、咖啡等官网未单独收录的品项也能被正确推荐。

### 它解决什么问题

"今天吃啥"是每天都会遇到的小事。常见痛点：

- 打开外卖 App 要翻半天菜单，最后还是点老样子
- 拿不定主意时想要一个明确的建议，而不是再问三个问题
- 想吃麦当劳但又有点在乎热量，纠结半天
- 换了个城市/门店，不知道当地在售什么

这个助手的做法：**问一两个问题 → 直接给完整方案**。方案里每道商品都标注了官网原文描述和营养数据，不用自己去商品详情页翻。

## 功能

### 1. 场景化推荐

不是干巴巴念菜单，而是按你的场景挑：

| 你说 | 它会做 |
|---|---|
| 「随便配个早餐」 | 挑饱腹组合，避开过辣 |
| 「加班到十点，随便来一套」 | 高能量档，扛饿 |
| 「给孩子点」 | 低刺激口味，避开麦辣鸡腿堡这类 |
| 「想吃得轻一点」 | 无糖可乐 + 低脂小食，给能量汇总 |
| 「请客，两个人」 | 先问人数再按份量配齐 |

完整搭配逻辑见 [`references/recipes.md`](references/recipes.md)。

### 2. 随机混搭 + 押韵顺口溜

每套随机套餐都会带一段**顺口溜评价**：

```
今天想吃顿好的
主角巨无霸，咬一口就懂了
　└ 双层牛肉饼，分量实在
薯条垫一口，越吃越有
　└ 现炸薯条，脆得刚好
圆筒冰淇淋收尾，甜到心里去
　└ 甜筒一握，孩子最爱
来口可口可乐，舒坦又解压
这一顿吃值了
```

顺口溜按热量档位选韵脚（高/中/低三套韵脚不同），商品名每套只出现一次，有专属口感的商品会追加一句特征描写。

### 3. 能量约束

```bash
python scripts/combo.py random --max-kj 2500
```

健身或控量场景可用。找不到低于该能量的完整套餐时，会**如实标注超出上限**，不会静默返回超限结果。

### 4. 点餐记录

```bash
python scripts/orders.py stats 小王
```

记录每次点了什么、几号点的、最常点哪款、口味偏向。第二次来时会主动接话：「看你上次点了巨无霸，这次要不要再来？」

### 5. 下单前必须确认

走 MCP 真实下单时，先调 `calculate-price` 把商品、优惠、配送费、应付金额完整念给你，得到明确同意才提交。

## 安装

### 前置条件

1. **Python 3.8+**，无需任何第三方库
2. **麦当劳 MCP Token**（免费，用于查询真实在售餐品、价格、优惠券）

### 获取 MCP Token

1. 打开 https://open.mcd.cn/mcp
2. 右上角【登录】，手机号验证
3. 登录后右上角变为【控制台】，点击【激活】申请 Token
4. 同意服务协议后即可复制 Token

### 配置 MCP

在 WorkBuddy 中：左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置MCP】，填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

保存后启用 `mcd-mcp`。也支持 Claude Code、Cursor、Cherry Studio 等任意兼容 Streamable HTTP 的客户端。

### 安装 Skill

把整个目录放进你的 skills 目录：

```bash
# WorkBuddy
~/.workbuddy/skills/mcd-order-assistant/
# 或项目级
.workbuddy/skills/mcd-order-assistant/
```

- **上班族**：午餐纠结症、工作日早餐快速决策

## 设计原则

**商品卖点只引官网原文，不改写、不编造。** 合并商品库时，MCP 独有的品项（官网无对应页面）描述留空，输出时明确标注「该商品官网暂无描述，以门店/官方渠道展示为准」——宁可不说，也不编。随机选品时，有官网描述的商品权重更高（热门 3 + 有描述 2 + 普通 1），让推荐优先落在有权威依据的品项上。

**价格不编造。** 售价随门店、时段、活动变动，一律实时查 MCP。本项目不含任何价格表。

**MCP 不可用也能用。** 商品推荐、随机套餐、点餐记录基于本地商品库正常运行，仅优惠券、实时价格、真实下单这三项不可用，并会明确告知用户。

**下单前必须确认。** 任何涉及真实下单、扣款的操作，先完整复述订单内容，得到明确同意才执行。

本项目为麦当劳程序员创意开发大赛参赛作品，由参赛者独立开发，非麦当劳官方产品。

商品描述引自麦当劳官网，营养数据以单份计量、官方标注更新至 2025 年 4 月，实际供应可能因批次与产地略有差异。餐品信息、价格及供应状态以麦当劳官方渠道的实时结果为准。本项目输出仅供参考，不构成医疗、营养或其他专业建议。

使用麦当劳 MCP 服务须遵守麦当劳中国的《使用条款》及《麦当劳 MCP 服务规则》。
